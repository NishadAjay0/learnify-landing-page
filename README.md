# Learnify — Responsive Product Landing Page

A responsive landing page concept for a fictional online learning platform.

## Target Audience
College students, beginners, and learners who want to build practical digital skills online.

## Features
- Responsive desktop, tablet, and mobile layouts
- Header navigation and call-to-action buttons
- Hero section with learning dashboard illustration
- Three feature cards and three course cards
- Learner testimonial cards
- Call-to-action banner and footer
- Shared color, typography, border-radius, and spacing tokens

## Reusable Components
1. Navigation bar
2. Primary and secondary buttons
3. Feature card
4. Course card
5. Testimonial card
6. Call-to-action banner
7. Footer

## Design System
- Primary: `#635BFF`
- Secondary: `#A855F7`
- Light background: `#F5F7FF`
- Dark text: `#17233F`
- Muted text: `#65718B`
- Accent: `#FF7316`
- Typography: Inter with system sans-serif fallbacks

## How to Preview
Open `index.html` in any modern web browser.

## Design Rationale
Learnify uses a friendly purple palette, clear visual hierarchy, rounded cards, and concise content. Responsive grids adapt the layout to narrower screens while shared design tokens maintain visual consistency.

## Note
Learnify is a fictional educational concept created for a student assignment. Course ratings and learner testimonials are illustrative sample content.
